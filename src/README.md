src/
- Contém o código-fonte em JavaScript do jogo (módulos ES).
- Estrutura principal:
	- `src/main.js`: inicializa o jogo e registra cenas.
	- `src/scenes/`: cenas do jogo (Menu, CharacterSelect, Game, GameOver).
	- `src/data/`: presets e dados (ex.: `characters.js` com presets de personagem).

Pasta base para desenvolvimento e empacotamento (web/Electron). Commitar esta pasta ao usar controle de versão.
