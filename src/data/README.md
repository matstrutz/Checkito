data/

Atualmente:
- `characters.js` — presets de personagens jogáveis e inimigos. Cada preset fornece uma lista inicial de peças com coordenadas `x,y`, tipo `pt` e `id`.

Use esta pasta para armazenar configurações, tabelas de balanceamento, e outros dados que podem ser carregados pelo jogo.
