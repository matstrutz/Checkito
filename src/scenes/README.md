scenes/
- Contém as cenas do jogo. Cada cena é um módulo ES e é registrada em `src/main.js`.

Principais cenas disponíveis:
- `MenuScene.js` — tela inicial, agora abre o seletor de personagens.
- `CharacterSelectScene.js` — seleciona o personagem do jogador antes do jogo.
- `GameScene.js` — lógica do jogo: tabuleiro, regras, IA, UI de promoção.
- `GameOverScene.js` — tela de fim de jogo e reinício.

Onde adicionar novas cenas
- Crie o arquivo na pasta e registre-o em `src/main.js`.
